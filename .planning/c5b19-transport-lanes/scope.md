## Exact minimal contract

Append one error-only pure function, for example:

`validateTransportLanes(events [][]byte, frozen obligationBindings, numer, denom uint32) error`

Names are implementation choices; semantics below are frozen. No receiver, returned observations, state ledger, serialization or dependency. Error-only avoids unnecessary owned-result structures and cannot leak partial validation facts.

1. Validate frozen obligation context and nonzero timebase even when events is nil/empty, using the existing encodeObligationPreimage convention. Valid empty selection succeeds with no evidence. Invalid context refuses always.
2. At most18 selected entries. Each entry must independently pass decodeEventFields for the same frozen context/timebase and have kind3–8 inclusive. A nil/empty/truncated/overlong or malformed selected event refuses; omission of the entire event is undetectable. The existing decoder enforces control lane1 for3/4/7/8 and worker lane2 for5/6. No harness event is admitted.
3. At most3 entries of each kind and at most3 distinct operationID byte arrays across all entries. Duplicate (kind, operationID) refuses even when bytes differ or are identical. Generation, digest or outcome differences do not create another operation identity for counting/deduplication. Different kinds sharing an operationID are allowed; this function does not check their other tuple fields agree.
4. For every pair of supplied events in the same lane, sequence values must differ. If eventA.Sequence < eventB.Sequence, require eventA.Tick <= eventB.Tick; if greater, require eventA.Tick >= eventB.Tick. Input order has no meaning. Compare unsigned values directly, with no subtraction or signed casts.
5. Equal ticks with distinct sequences are valid. Sequence gaps and nonzero starting sequences are valid partial selections; do not require adjacency, lane completeness or a starting index. Zero/max sequence and tick values retain existing strict decoder behavior; this layer adds no special sentinel or overflow arithmetic.
6. Different lanes may reuse the same sequence and have arbitrary relative ticks. Do not create a global watermark, compare cross-lane ticks or use numeric operation/generation order as event order.
7. Never mutate/reorder the input outer slice or inner byte arrays, frozen bindings or any history. Decode into bounded local value arrays; pairwise checks on at most18 events are sufficient. Success/error retains no caller bytes or state. A late invalid event still returns only an error; there is no partially successful output.

This check is explicitly independent of frame/sidecar, local write-result pair, received/applied and decision-history validation. It must not call those APIs as implicit composition, synthesize absent events or require complete pairs. A lone kind4 or kind8 may pass this partial lane check if individually strict; that does not validate a write or application. Likewise different kinds with one operationID but different strict generation/digest/outcome fields may pass this layer if lane constraints hold. Retain an explicit test for that separation to prevent an accidental correspondence claim. No raw frames are accepted by this API; no independent receipt or raw-byte identity is established.
