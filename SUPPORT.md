# Support

Capsule is pre-release research software. It does not currently provide a supported sandbox or a
security boundary for hostile code.

## Questions and usage help

Use GitHub Discussions when enabled. Until then, use a GitHub issue for reproducible setup,
documentation, or development questions. Include the operating system, Go and Node.js versions,
backend tier, and relevant command output.

## Bugs and feature proposals

Use the repository issue templates. Feature proposals should describe the narrow capability
required and why an existing capability cannot express the workload.

## Security reports

Do not use issues or discussions for suspected sandbox escapes, credential exposure, isolation
failures, or other vulnerabilities. Follow [SECURITY.md](SECURITY.md) instead.

## Compatibility and releases

No released version is currently supported. Compatibility, deprecation, and release-support
policies will be defined before the first public release.
