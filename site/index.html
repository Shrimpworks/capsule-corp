capsule

The task, not the machine.

Bounded work. Explicit authority.

Capsule explores a local-first execution model for bounded JavaScript and TypeScript jobs proposed by AI agents. The intended design separates planning, human authorization, content custody, and hostile-guest execution.

Open the repository → Read the project brief →

An agent proposes. The daemon plans. A trusted Broker obtains human authorization. Only the Execution Supervisor may create a hostile guest.

Intended authority rule

Authority stays separated.

The language runtime is not the host security boundary. External isolation is mandatory, and the public abstraction remains a bounded job rather than a shell, virtual machine, or development environment.
