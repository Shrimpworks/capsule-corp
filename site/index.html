capsule

No ambient authority.

A runtime boundary for agent-generated work.

Capsule is an experimental, capability-controlled JavaScript and TypeScript task runtime. An agent proposes code, inputs, limits, and expected outputs. The trusted host resolves that request into one immutable plan, and the user approves its exact digest.

Open the repository → Read the project brief →

The model proposes work. The trusted host resolves the plan. The user approves the exact authority. Capsule controls execution, egress, and the signed receipt.

Core rule

One job. Four signed stages.

The first slice stays deliberately narrow so the security claims stay testable.

  1. 1.0

    Propose.

    The agent submits source, requested inputs, limits, and expected outputs.

  2. 2.0

    Plan & approve.

    The host resolves exact authority. The user approves that immutable plan digest.

  3. 3.0

    Isolate.

    A disposable Apple Container or gVisor-backed runtime executes the approved plan.

  4. 4.0

    Release.

    The broker validates approved artifacts and emits a device-signed receipt.

The language runtime is not the boundary.

Go coordinates trusted policy and lifecycle work. External isolation contains the hostile guest. Runtime permissions remain supplemental hardening.
